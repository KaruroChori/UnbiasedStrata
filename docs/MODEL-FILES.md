## Request shapes a coding agent sends (step 7)

`frontend/tests/shapes-real-engine.sh` against a live server: no `max_tokens`; `max_tokens` 32768 with a short
answer (clamped to what the context leaves, not refused); a prior assistant message carrying `reasoning_content` and
`tool_calls` followed by a tool result; two tool calls in one turn; a call whose optional arguments come before the
required one; a client that disconnects two seconds into a long stream, then a clean request; an 18k-token prompt
streamed. Results per box and model are under `bench/unbiased/*-step7-shapes/`. The pinned llama.cpp server sends an
SSE ping only after 30 s of silence (`--sse-ping-interval`, default 30); an 18k-token prompt on Qwen3.6 is read in
5 s, so no ping is seen there. Run lines for long prompts should pass `--sse-ping-interval 10` if the client times out
sooner.
